# 环境配置说明

> **安全**：真实密钥只放在项目根目录 **`.env`**（已加入 `.gitignore`）。本文档**不**写入完整 Key，避免误提交 Git 或泄露。

---

## DeepSeek API

| 变量 | 说明 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 在 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建，已写入本地 `.env` |
| `DEEPSEEK_BASE_URL` | 默认 `https://api.deepseek.com`（OpenAI 兼容） |
| `DEEPSEEK_MODEL` | 默认 `deepseek-v4-flash` |

程序通过 `python-dotenv` 读取（见 `plan/M01-配置与密钥.md`）。

**验证（实现 M02 后）**：

```powershell
cd D:\code\bilibili_transcriber
python -c "from dotenv import load_dotenv; import os; load_dotenv(); print('Key 已加载:', bool(os.getenv('DEEPSEEK_API_KEY')))"
```
