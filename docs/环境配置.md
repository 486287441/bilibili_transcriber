# 环境配置说明

> **安全**：用户只在本机 Web 设置页填写 DeepSeek Key。程序将其保存到已被 `.gitignore` 排除的 `.env`，Agent 不读取、不代填，也不要求用户发送到聊天。

---

## DeepSeek API

| 变量 | 说明 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 用户在 [DeepSeek Key 页面](https://platform.deepseek.com/api_keys) 创建，然后亲自在 Web 设置的“API 配置”中填写 |
| `DEEPSEEK_BASE_URL` | 默认 `https://api.deepseek.com`（OpenAI 兼容） |
| `DEEPSEEK_MODEL` | 默认 `deepseek-v4-pro` |

程序保存后立即生效，并同步写入本地 `.env` 供下次启动读取。

**安全验证**（只检查布尔状态，不读取 Key）：

```powershell
Invoke-RestMethod http://127.0.0.1:8765/api/settings/secrets
```
