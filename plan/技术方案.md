> 依据已定 `需求.md`。产品决策不得在本方案中推翻。

---

## 1. 技术选型结论

| 能力 | 选型 | 理由（对应 PRD） |
| --- | --- | --- |
| 语言与运行时 | 现有 **Python 3.12** 单脚本演进为「主程序 + 小模块」 | 与 SenseVoice / yt-dlp 栈一致 |
| AI 润色与摘要 | **DeepSeek API**（OpenAI 兼容 `chat/completions`） | PRD 指定；密钥见 `.env` |
| 飞书写入 | **lark-cli** wiki 建节点 + docx v2 写入 | `fixed_wiki`、每视频一篇 doc |
| 鉴权 | 飞书：`lark-cli` 用户身份 `auth login` | 用户已完成 CLI 登录 |
| 配置 | **`.env`** + `python-dotenv` | DeepSeek + wiki 空间参数 |

## 3. 运行与部署

1. 填写 `.env`（DeepSeek 已配置；补 `FEISHU_WIKI_SPACE_ID`、`FEISHU_WIKI_PARENT_NODE_TOKEN`）。
2. `pip install -r requirements.txt`（含 `openai`、`python-dotenv`、`httpx`）。
3. `python bilibili_transcriber.py` 或现有 `启动程序.bat`。
4. 飞书应用需发布并加入目标知识库可编辑成员。

---

## 4. 数据流

1. 复制 B 站链接 → yt-dlp 下载音频 + 取 `title`、`webpage_url`
2. SenseVoice 转写 → `raw_text`
3. DeepSeek：`polish_and_summarize(raw_text)` → Markdown
4. 在固定知识库父节点下 **新建** docx（标题：`YYYY-MM-DD 视频标题`）
5. 写入 rich_header + DeepSeek 正文
6. 打印飞书 URL；失败 → `fallback_to_doubao(raw_text)`

---

## 5. 与 PRD 对应表

| PRD 决策 | 实现要点 |
| --- | --- |
| auto_immediate | 转写成功后立即 `postprocess_and_publish` |
| polish_plus_summary | `prompts.POLISH_AND_SUMMARY` |
| one_video_one_doc | 每视频 `create_video_document`，无周记合并 |
| fixed_wiki | `.env` 中 wiki 空间与父节点 |
| fallback_clipboard_doubao | 异常时剪贴板 + 打开豆包 |
| replace_fully | 成功路径不 `start doubao` |
| rich_header | 标题、链接、转写时间三行 |
